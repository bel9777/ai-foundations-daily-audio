Alex: Jordan, I was looking at that October 2026 paper on arXiv called PotentialEP. The researchers trained CIFAR-scale generative models without backpropagation, using equilibrium propagation instead. Are we actually close to ditching backprop?
Jordan: Not in production, no. It is an interesting research preprint because backprop requires global gradient transport. Error signals have to travel backward through the entire architecture, which is a massive headache if you want to build analog hardware.
Alex: Right, and another 2026 preprint, Split Forward Gradients, made a related point: holding onto all those intermediate activations from the forward pass consumes an enormous amount of memory.
Jordan: Exactly. But every frontier language model in the real world is still trained with backpropagation. The alternatives are worth tracking, but backprop remains the workhorse.
Alex: Every frontier model you interact with was shaped by running this exact calculation trillions of times. This is AI Foundations, lesson 21.
Jordan: In lessons 19 and 20, we covered the forward pass, where inputs flow through layers to make a prediction. Today is about the backward pass: how one single error number gets traced back through millions or billions of weights so each one knows which way to adjust.
Alex: And it really does require just one single number to start, right? The loss.
Jordan: Always. You cannot assign credit for the error until that error is defined as a single scalar. Squared error for regression, cross-entropy for next-token prediction. Once you have that loss, backprop calculates the gradient, which is just the sensitivity of the loss to every single weight.
Alex: So the partial derivative of loss with respect to a weight answers: if I nudge this weight up slightly, how much does the loss change, and does it go up or down?
Jordan: That is it. A big positive gradient means the weight is pushing the loss up, so turn it down. Near zero means it barely matters for that batch. To compute that across layers, we use the chain rule. A neural network is just a chain of simple operations. Sensitivities multiply along any single path. If an intermediate value branches out into multiple downstream paths, their contributions add up.
Alex: I loved your university budget analogy for this.
Jordan: Imagine a university misses its budget by two million dollars. That total variance is your loss. You would never run twenty thousand separate scenarios where you tweak one line item at a time to see what happens. That brute-force method is finite differences, and it would take forever. Instead, you start at the top total and work backward down the org chart. Each department head takes the variance handed down and splits it among the line items based on how strongly each one fed into the total.
Alex: One backward pass gives every line item its share of the miss. That is reverse-mode automatic differentiation.
Jordan: Exactly. It was popularized by Rumelhart, Hinton, and Williams back in 1986, building on Paul Werbos. Computationally, Kaplan and others showed training takes about six N FLOPs per token for an N-parameter model, compared to two N for the forward pass alone. So the backward pass takes roughly twice the forward pass. The big trade-off is memory. You must store all the intermediate activations from the forward pass so the backward pass can use them.
Alex: And backprop only calculates the blame. It does not update the weights. That is the optimizer's job.
Jordan: Right. Standard gradient descent takes a step proportional to the learning rate. AdamW adapts step sizes per weight. Newer optimizers like Muon orthogonalize the updates for weight matrices, which open frontier Mixture-of-Experts models have started adopting. But all of them consume the exact same gradients from backprop.
Alex: Let us walk through the two-weight example from the lesson. Input x is 2. Weight one is 0.5. Hidden value h is ReLU of weight one times x. Weight two is 3. Prediction is weight two times h, and our target y is 1.
Jordan: Forward pass: 0.5 times 2 is 1. ReLU of 1 is 1. Then 3 times 1 gives a prediction of 3. Target is 1, so our squared error loss is 3 minus 1 squared, which is 4.
Alex: Now run the tape backward.
Jordan: The derivative of squared error is two times prediction minus target, so two times 2 is 4. That is the error signal entering the network. For weight two, we multiply that 4 by its input h, which is 1. So weight two gets a gradient of 4.
Alex: And for weight one?
Jordan: The blame travels backward through weight two, multiplying 4 by 3 to get 12. The ReLU derivative is 1 because its input was positive, so 12 passes through unchanged. Finally, we multiply by input x, which is 2. Twelve times 2 is 24.
Alex: Weight one gets a gradient of 24, while weight two only gets 4. It gets six times the blame because weight two amplified it downstream and x amplified it upstream. If you nudge weight one by point-zero-zero-one, the loss changes by point-zero-two-four. It matches perfectly.
Jordan: And in PyTorch, the tape-based autograd engine does this behind the scenes. It records the graph during the forward pass, and calling backward plays that tape in reverse.
Alex: Ready for the quiz. Hit me.
Jordan: Question one. In an email triage network, one input feature is raw hour received, from 0 to 23, while other features are standardized. Using our formula where weight gradient equals input transpose times blame, what happens?
Alex: The raw feature produces gradients ten to twenty times larger because the gradient scales directly with the input magnitude. A single learning rate will make that feature oscillate or diverge while the standardized features barely move at all.
Jordan: Spot on. Question two. A colleague has a thirty-layer network where the top layers learn fine, but the first layer barely moves. What is happening, and which activation makes it worse?
Alex: Vanishing gradients. The chain rule multiplies thirty local slopes together. If those numbers are below one, the product shrinks toward zero before reaching layer one. Sigmoid makes it much worse because its maximum derivative is only point-two-five.
Jordan: Question three. Training loss drops to point-zero-two, but on held-out data the model claims ninety-five percent confidence while only getting seventy percent right. What two things do you check, and why did backprop cause this?
Alex: Check calibration with a reliability diagram, and check validation loss across cross-validation folds. Backprop caused this because it kept driving training log loss down, pushing logits to extremes to shave off decimals, which breeds overconfidence on unseen data.
