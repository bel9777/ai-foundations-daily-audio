Alex: Where do people usually trip up when running this lab?
Jordan: Three main traps. First, file ordering. If you run metrics before score, you get a file not found or a missing score key. Second, flipping the positive class. If your code accidentally treats normal invoices as positive, precision jumps to ninety-seven percent everywhere, matching the base rate. If your metric looks suspiciously like your base rate, your labels are probably backwards.
