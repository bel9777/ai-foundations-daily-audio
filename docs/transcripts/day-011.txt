AI Foundations — Day 11: Optimization and Gradient Descent

Day 11: Optimization and Gradient Descent Objective: By the end of today, you should understand how an AI model actually improves its predictions by repeatedly making small changes that reduce error. Prerequisites: You should already be comfortable with features, labeled examples, and loss functions from Days 9 and 10. Those ideas matter today because optimization uses features as inputs, labeled examples as training data, and a loss function as the score we try to reduce. 1) The big idea: training is a search problem When we train a model, we are usually trying to find the set of internal settings that makes the model’s predictions as good as possible on the training data. Those internal settings are often called parameters . A parameter is a number inside the model that controls its behavior. For example, in a simple line-fitting model, the slope and intercept are parameters. Optimization is the process of finding the best parameter values according to a goal. In machine learning, that goal is usually to make the loss function as small as possible. So the training process is really a search: “Which parameter values produce the lowest loss?” 2) Gradient descent: a practical way to improve step by step Gradient descent is one of the most common optimization methods. It works by making small changes to the parameters in the direction that reduces loss. The name sounds intimidating, but the basic idea is simple: Measure how wrong the model is using the loss function. Check which direction would make the loss go down. Move the parameters a small amount in that direction. Repeat many times. The gradient is a set of values that tells us how sensitive the loss is to each parameter. In plain language, it answers: “If I change this parameter a little bit, does the loss get better or worse, and by how much?” A useful analogy is a hiker in fog. Imagine you are standing on a mountain and want to get to the lowest valley, but you cannot see far ahead. You can still feel the slope under your feet. If you take the steepest downward step repeatedly, you will usually move toward lower ground. Gradient descent is like that: the model feels the slope of the loss surface and takes small downhill steps. 3) Learning rate: step size matters The learning rate is the size of each step in gradient descent. It is a number that controls how far the model moves each time it updates its parameters. This matters because: If the learning rate is too small, training can be very slow. If the learning rate is too large, the model can overshoot the best values and bounce around or even get worse. Think of it like adjusting a recipe. If the soup is too salty, adding one grain of rice at a time might help, but it will take forever. Dumping in a huge bag of rice might ruin the soup. The learning rate is about choosing a sensible adjustment size. 4) Loss surface: what the model is “walking on” A loss surface is a way of imagining the loss value for many different parameter settings. If you picture every possible parameter choice as a point on a landscape, then the height of the landscape is the loss. Low areas are good because they represent smaller error. High areas are bad because they represent larger error. Gradient descent does not guarantee the perfect answer in every case, but it is often effective because it steadily pushes the model toward lower loss. That is why many AI systems improve through repeated training rather than a single clever guess. 5) A concrete example: predicting house prices Suppose we want to predict house prices using two features from Day 9: square footage and number of bedrooms . We choose a simple model that combines those features with parameters. At first, the model may make poor predictions, which gives us a high loss. Training then works like this: The model predicts a price for each labeled example. We compare each prediction to the true price using the loss function. We calculate the gradient to see which parameters caused the largest errors. We update the parameters slightly to reduce the loss. After many updates, the model can become much better at fitting the training data. The important point is that the model does not “understand” houses the way a person does. It improves by repeatedly adjusting numbers in response to error. Review: connect today to earlier lessons From Day 10: loss functions define what wrong means. Gradient descent needs that definition before it can improve anything. Without a loss function, optimization has no target. From Day 6: labeled examples provide the correct answers that let us measure error during training. Gradient descent uses those examples to see whether changes to the model help or hurt. From Day 9: features are the inputs. Optimization does not create features; it adjusts the model’s internal numbers so it can use those features more effectively. Free hands-on exercise: simulate gradient descent with pencil and paper You do not need any paid tools for this exercise. Pick a simple goal: pretend you want to predict a number close to 10. Start with a guess, such as 2. Define a simple loss: loss = (guess - 10)^2 . Now improve your guess in small steps. If your guess is too low, increase it. If it is too high, decrease it. Try step sizes of 1, then 0.5, then 0.1. Notice which step size gets you close fastest without overshooting too much. If you want a slightly richer version, use a notebook and make a tiny table with columns for guess , loss , and next guess . Even this toy exercise shows the core logic of optimization. Three knowledge-check questions 1) What is the purpose of optimization in machine learning? 2) What does the learning rate control? 3) Why does gradient descent need a loss function? ------------------------------ Answers 1) Optimization searches for parameter values that make the model’s loss as small as possible. 2) The learning rate controls the size of each update step during training. 3) Gradient descent needs a loss function because the loss tells it what “better” means and which direction to move.
