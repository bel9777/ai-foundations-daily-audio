AI Foundations — Day 20: Layers, Activations, and Representations

Day 20 — Layers, Activations, and Representations Objective: understand what layers do inside a neural network, why activation functions matter, and how networks build representations step by step. Prerequisites: you should be comfortable with the basics of neurons from Day 19, plus the earlier ideas of linear models, baselines, and why probability calibration matters when judging predictions. Yesterday you saw a neural network as a collection of simple units. Today we’ll zoom in on the parts that make it useful. The big idea is that a network does not just “predict” directly; it transforms data through layers , and each layer creates a new representation of the input. 1) What a layer is A layer is a group of neurons that all take the same input and produce a new set of outputs. Think of a layer as a stage in a factory line. The first stage receives raw material, the next stage reshapes it, and later stages refine it further. In a simple network: The input layer receives the raw features, such as age, income, or pixel values. A hidden layer is any layer between input and output. It is called “hidden” because you do not directly provide it with labels, and its internal values are usually not the final answer. The output layer produces the prediction, such as a score, a probability, or a class label. Each neuron in a layer usually performs two steps: It computes a weighted sum of its inputs plus a bias. It sends that result through an activation function. This is the same “linear part + non-linear part” pattern you met in Day 19. 2) Why activation functions matter An activation function is a mathematical rule that changes a neuron’s raw score into its output. It decides how strongly the neuron “fires.” Why not just use the raw score directly? Because a network made only of linear steps would still be linear overall. That means stacking more layers would not give you richer behavior; it would collapse into one big linear model. This is one of the limits you saw when we discussed linear models on Day 16. Activation functions add nonlinearity , which means the network can bend, combine, and separate patterns that a straight line cannot. In plain language: nonlinearity lets the model describe more complicated relationships. Common activation functions include: ReLU (Rectified Linear Unit): outputs 0 for negative inputs and the input itself for positive inputs. It is simple and widely used. Sigmoid : squeezes values into the range 0 to 1, which is useful when the output should behave like a probability-like score. Tanh : squeezes values into the range -1 to 1. At this stage, do not worry about memorizing formulas. The important point is the job they do: they help the network express patterns that a plain linear model cannot. 3) Representations: what the network is learning A representation is a new way of encoding the same input so that the next part of the network can use it more easily. A representation is not the final prediction; it is an intermediate description of the data. Here is the key insight: each hidden layer can turn the data into features that are more useful than the original ones. Early layers tend to learn simple patterns, while later layers combine those patterns into more abstract ones. For example, in image recognition: Early layers may react to edges and simple textures. Middle layers may combine edges into shapes or parts. Later layers may combine parts into object-level concepts. This is why neural networks are often described as representation learners . They do not only fit a label; they build internal descriptions that help solve the task. 4) A memorable analogy Imagine you are trying to recognize a song by listening to a noisy recording. The raw waveform is like the input. One layer might isolate beats and frequencies. Another layer might group those into melody patterns. A later layer might recognize the actual song. The activations are like the rules each listener uses to decide what sounds matter. The representation is the evolving mental model of the recording at each stage. The song becomes easier to identify because each layer makes the signal more meaningful. 5) Concrete real-world example: spam detection Suppose you want to classify emails as spam or not spam. The input might include words, sender metadata, and formatting clues. A first hidden layer could learn to detect patterns like urgent language, suspicious links, or unusual punctuation. A second hidden layer could combine those signals into broader suspicious behavior. The output layer could produce a score that is turned into a probability that the email is spam. Notice how the network is not just memorizing one rule. It is building layered representations from simpler signals. That is the difference between a shallow rule and a learned internal structure. 6) Review of earlier ideas From Day 16: linear models are limited because they can only draw straight boundaries in feature space. Today’s activations give neural networks the nonlinearity needed to go beyond that limit. From Day 18: confidence should be interpreted carefully. Even if a network outputs a number between 0 and 1, that does not automatically mean it is well-calibrated. The output layer can produce a score that behaves like probability, but you still need to check whether those scores match reality. From Day 15: always compare against a simple baseline. A deeper network is not automatically better just because it has more layers. The baseline reminds you to ask whether the added complexity is actually helping. 7) Hands-on exercise: build intuition with paper or a spreadsheet You can do this without any paid tools. Pick two input numbers, such as x1 = 2 and x2 = -1 . Choose a simple weighted sum for one neuron, for example z = 1.5x1 - 2x2 + 0.5 . Compute z . Now apply a simple activation rule by hand: ReLU: output 0 if z < 0 , otherwise output z . Sigmoid approximation: notice whether z is very negative, near zero, or very positive, and think about whether the output should be near 0, around 0.5, or near 1. Repeat with a second layer: take the first output as the input to another weighted sum. Write down how the meaning of the number changes at each step. As you do this, ask yourself: “What does each layer make easier for the next layer?” That question is the heart of representation learning. Knowledge check 1.
