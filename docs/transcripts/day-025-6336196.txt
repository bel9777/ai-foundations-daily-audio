AI Foundations — Day 25: Attention: Choosing What Matters

Day 25: Attention — Choosing What Matters Objective: Learn how attention helps a model focus on the most relevant parts of a sequence, why that matters for language and other ordered data, and how this idea prepares us for transformers tomorrow. Prerequisites: You should be comfortable with embeddings as vectors of meaning, basic sequence models (like RNNs and LSTMs), and the idea that neural networks learn by adjusting parameters through backpropagation. Up to now, we have built the pieces needed to understand one of the most important ideas in modern AI: attention . Attention is a method that lets a model decide, for each step, which earlier pieces of information matter most right now . Instead of forcing the model to compress everything into one fixed memory, attention gives it a way to look back selectively. This lesson has four connected ideas: What attention is in plain language How a model scores and weights information Why attention helps with long sequences How attention relates to embeddings and sequence models 1) The basic problem: not all information matters equally Imagine reading this sentence: “The cat, which had been sleeping on the warm windowsill all afternoon, suddenly jumped.” If you want to understand who jumped, the word cat matters much more than windowsill . A good model should be able to focus on the useful part and ignore the rest. That is the core idea of attention: choose what matters . In older sequence models, information had to pass through a chain of hidden states. A hidden state is the model’s internal memory at a particular time step. This works, but it can be difficult for the model to keep track of important details over long distances. Attention gives the model a shortcut: it can inspect earlier hidden states directly. 2) How attention works: scores, weights, and context Attention usually begins with three vectors: Query : the thing asking for useful information Key : a description of what each item offers Value : the actual information to pass along These are just learned vector representations. A vector is a list of numbers. In this context, vectors are how a model stores and compares meaning. Here is the basic process: The query is compared with each key. Each comparison produces a score , which is a number showing how relevant that item seems. The scores are turned into weights , which are numbers that add up to 1. The weights are used to blend the values into one new vector called the context vector . A context vector is a summary made from the most relevant pieces of information for the current step. You can think of it like searching through a pile of notes. The query is your question, the keys are the labels on the notes, the scores are how well each label matches your question, and the values are the content of the notes. The model does not read every note equally. It gives more importance to the ones that best answer the question. Memorable analogy: the spotlight Attention is like a stage spotlight. A theater has many actors on stage, but the spotlight makes some actors easier to see than others. The spotlight does not remove the other actors; it simply changes what the audience notices right now. In the same way, attention does not delete earlier information. It assigns different importance to different parts of the sequence depending on the current need. 3) Why attention helps sequence models Let’s connect this to the sequence models from Day 24. In a simple RNN, the model reads one item at a time and keeps updating its hidden state. That hidden state can become a bottleneck: if a useful detail appeared many steps ago, it may be hard to preserve it perfectly. Attention helps by allowing the model to look back at many earlier states directly instead of relying on one compressed memory. This has several benefits: Better handling of long-range dependencies : a long-range dependency is a relationship between items far apart in a sequence. More flexible memory : the model can focus on different past items at different times. Improved interpretability : attention weights can sometimes show which parts of the input influenced a decision. This does not mean attention is perfect or magically “understands” language. It means the model has a more direct way to choose relevant information. 4) A concrete real-world example: translating a sentence Suppose a model is translating from English to another language. When it generates each output word, it may need to look back at different input words. For example, in the sentence “The book that I bought yesterday was expensive,” the model may need to focus on book when producing the main subject, but later focus on yesterday when handling time-related meaning. Attention lets the model shift focus as needed for each output step. This is much more natural than trying to squeeze the entire sentence into one fixed-size summary before generating anything. 5) How attention connects to embeddings and backpropagation Attention works on vectors, so it depends on the embedding idea from Day 23. An embedding is a learned vector representation that places similar meanings near each other in vector space. Attention uses these vectors to compare meaning and importance. Attention also works well with backpropagation from Day 21. The model learns which query-key comparisons and value combinations are useful because errors flow backward through the network and adjust the parameters. In other words, the system learns not only what information to store, but also when to focus on it. And this is related to deep training from Day 22: attention can make optimization easier in some architectures because information has more direct routes through the network. Earlier ideas about stable training still matter here. Good models need good gradients, good initialization, and sensible architecture choices. Free hands-on exercise Try this with no paid tools: Write down this short sentence: “The dog chased the ball because it was excited.” Ask yourself: what does it refer to? Now list the important words in the sentence: dog , chased , ball , because , excited . Assign each word a simple relevance score from 0 to 3 for answering the question “Who was excited?” Notice how a model with attention would give higher weight to dog than to ball . Then repeat with the sentence: “The dog chased the ball because it rolled away.” This time, what does it refer to? You will see why attention is useful: the same word can matter differently depending on context. Knowledge check 1. In plain language, what does attention help a model do? 2. Because the model can look back directly at many earlier items instead of relying only on one compressed hidden state. Wrap-up Today we learned that attention is a mechanism for selective focus. It uses queries, keys, and values to produce scores and weights, then combines information into a context vector. This helps models deal with long-range dependencies, work more flexibly with sequences, and use embeddings more effectively. Keep two earlier ideas in mind: from Day 23, meanings can be represented as vectors; from Day 24, sequence models process ordered data step by step. Attention connects those ideas by letting a model decide which vectors in the sequence deserve the most influence right now.
