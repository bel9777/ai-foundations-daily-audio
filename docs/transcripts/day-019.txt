AI Foundations — Day 19: Neural Networks from First Principles

AI Foundations — Day 19 Neural Networks from First Principles Estimated time: 8–12 minutes Hi Brian, Yesterday you learned that a model’s score is not automatically a trustworthy probability. Today we step inside a different family of models: neural networks. Objective By the end of this lesson, you should be able to explain how a neural network combines simple calculations into a flexible prediction system, what neurons, weights, layers, and activation functions do, and how training changes the network. Prerequisites You only need these earlier ideas: - A feature is an input the model can use. - A parameter is an adjustable number learned during training. - A loss function measures how wrong a prediction is. - Gradient descent updates parameters to reduce loss. - A linear model combines inputs using weighted addition. No biology or advanced math is required. The big idea A neural network is a model made from many small computational units arranged in layers. Each unit performs a simple calculation. Connected together, those simple calculations can represent complicated relationships. The name was loosely inspired by brains, but modern neural networks are mathematical systems—not simulated human minds. 1. A neuron is a small calculator An artificial neuron receives input values, multiplies each by a learned weight , adds them together with a bias , and passes the result through an activation function. In compact form: output = activation(weighted inputs + bias) New terms: - Weight: A learned parameter controlling how strongly an input affects the neuron. - Bias: A learned parameter that shifts when the neuron responds. - Activation function: A rule that transforms the neuron’s combined input before passing it onward. Suppose a neuron helps estimate whether a delivery will be late. Its inputs might include distance, order size, rain forecast, and departure delay. A large positive rain weight means rain pushes the neuron’s output upward; a negative early-departure weight could push it downward. One neuron is limited. Its power comes from being connected to others. 2. Layers organize the calculations Neural networks usually contain three kinds of layers: - Input layer: Receives the original features. - Hidden layers: Build intermediate representations from earlier values. - Output layer: Produces the final prediction. “Hidden” does not mean secret. It means these values are internal rather than supplied as inputs or shown as final outputs. A network that reads an order might gradually build useful internal signals: raw fields → delivery complexity → risk patterns → late/not late The training data does not have to label “delivery complexity.” The network may learn that intermediate representation because it helps reduce the final prediction loss. A representation is the way a model internally encodes useful information. Neural networks are powerful partly because they can learn representations instead of requiring people to hand-design every useful feature. 3. Activation functions create flexibility If every layer only performed weighted addition, stacking many layers would still collapse into one linear calculation. The network could not learn genuinely curved or irregular relationships. An activation function adds nonlinearity —the ability to model relationships that are not a single straight-line rule. A common activation is ReLU , short for rectified linear unit: - If the input is negative, output 0. - If the input is positive, keep it. That simple bend allows networks to combine many pieces into complex decision boundaries. For example, delivery risk may rise when distance is high and weather is bad, but not rise much when only one is true. Nonlinear layers can learn interactions like this more naturally than a basic linear model. 4. A forward pass produces a prediction A forward pass is the process of moving one example from the input layer, through the hidden layers, to the output. For a delivery-risk model: 1. The input layer receives the order’s features. 2. Each hidden neuron calculates an output. 3. Later layers combine those outputs. 4. The output layer produces a score or prediction. At this point, nothing has learned yet. The network has only calculated with its current weights and biases. Training begins when we compare that prediction with the true answer. 5. Backpropagation assigns responsibility for error After a forward pass, the loss function measures the error. The network then needs to determine how each of perhaps millions of parameters contributed to that error. Backpropagation is an efficient method for calculating how a small change in each parameter would affect the loss. It sends information about the error backward through the network. Those calculated directions are gradients—the same idea you met in gradient descent. The training loop is: 1. Make predictions with a forward pass. 2. Measure loss against the true answers. 3. Use backpropagation to calculate gradients. 4. Use an optimizer to update weights and biases. 5. Repeat over many batches of examples. Backpropagation calculates the gradients; gradient descent or another optimizer uses them to make updates. Those are related but distinct jobs. Analogy: a kitchen team adjusting a recipe Imagine a kitchen team makes soup through several stations. One person prepares vegetables, another builds the broth, another seasons it, and a final person plates it. A customer says the finished soup is too salty and lacks depth. The team must work backward to decide which station contributed to each problem. Then each station makes a small adjustment before the next batch. - The ingredients are the inputs. - Each station is a layer. - Recipe amounts are weights and biases. - The finished soup is the prediction. - The customer’s rating is the loss. - Working backward to assign responsibility is backpropagation. - Changing the recipe is the parameter update. No single station makes the whole soup. The sequence of small transformations creates the result. Concrete example: recognizing handwritten digits Suppose a network receives a 28-by-28-pixel image of a handwritten number. - The input is 784 pixel brightness values. - Early hidden layers may learn simple patterns such as edges and short curves. - Later layers may combine them into loops, intersections, and digit-like shapes. - The output layer produces ten scores, one for each digit from 0 through 9. If the image is a 3 but the model favors 8, the loss increases. Backpropagation calculates which weights contributed to that mistake, and the optimizer nudges them. Across many examples, useful internal representations emerge. The network is not storing a verbal rule like “a 3 has two right-facing curves.” It is learning numerical transformations that help distinguish the labeled examples. What depth does—and does not—mean A deep neural network simply has multiple hidden layers. More depth can let the model build more abstract representations in stages. But deeper is not automatically better. Larger networks can: - require more data and computing, - take longer and cost more to train, - overfit, - be harder to interpret, - fail when real-world data differs from training data. The familiar discipline still applies: compare against a baseline, validate honestly, choose metrics that match the goal, and monitor performance after deployment. Free hands-on exercise: build a tiny paper network No software is needed. Predict delivery risk using two inputs: - Rain forecast: 1 for rain, 0 for no rain - Departure delay: hours late Create two hidden neurons: - Weather pressure = ReLU(2 × rain + 0.5 × delay − 0.5) - Schedule pressure = ReLU(0.5 × rain + 2 × delay − 1) Then calculate: - Risk score = weather pressure + schedule pressure Try these cases: 1. No rain, no delay 2. Rain, no delay 3. No rain, one-hour delay 4. Rain, one-hour delay For each case, calculate both hidden values and the risk score. Then change one weight. What behavior changes? You have just performed a manual version of network inference and parameter experimentation. Three concepts to hold onto - A neural network is a layered mathematical function, not a miniature brain. - Hidden layers learn intermediate representations useful for prediction. - Training is still the familiar loop: predict, measure error, calculate gradients, update parameters. Knowledge check 1. Why would several neural-network layers without activation functions still behave like one linear model? 2. What is the difference between backpropagation and gradient descent? 3. In the handwritten-digit example, what might early and later hidden layers learn? --- Answers 1. Without nonlinear activation functions, each layer only performs linear operations. Multiple linear operations can be combined into one linear operation, so extra layers would not add the ability to model nonlinear relationships. 2. Backpropagation efficiently calculates how each parameter affects the loss—the gradients. Gradient descent or another optimizer uses those gradients to update the parameters. 3. Early layers might learn edges and simple curves. Later layers might combine those into loops, intersections, and larger digit-like patterns.
