AI Foundations — Day 21: Backpropagation: Assigning Credit for Error

Day 21 — Backpropagation: Assigning Credit for Error Objective: By the end of today, you will understand how a neural network learns from mistakes by tracing error backward through its layers and adjusting each weight a little bit in the right direction. Prerequisites: You should be comfortable with the ideas from Day 19 and Day 20: what a neural network is, what a layer does, what activations are, and how representations change as data moves forward through the network. Yesterday we talked about how layers and activations create useful representations. Today we answer the next question: once the network makes a mistake, how does it know which weights caused the mistake and how much to change them? That is the job of backpropagation . 1) The big idea: learning by assigning credit Backpropagation means “sending error information backward” through the network. More precisely, it is a method for figuring out how much each weight contributed to the final error. This is often called credit assignment : each parameter gets either some blame for making the prediction worse, or some credit for making it better. A parameter is a number the model learns from data. In a neural network, the main parameters are weights and biases . A weight controls how strongly one input affects the next layer. A bias is an extra number that shifts a layer’s output up or down. Think of a neural network like a row of people passing buckets of water to put out a fire. If the fire is still too big, you need to know where the chain failed. Backpropagation is the process of walking backward through the chain and asking: which person should pour a little more water next time, and by how much? 2) Loss: the score that tells us how wrong the network was To learn, the network needs a loss . A loss is a single number that measures how far the prediction was from the correct answer. A large loss means a bad prediction; a small loss means a good prediction. Here is the basic training loop: Forward pass: inputs move through the network to produce a prediction. Loss calculation: we compare the prediction to the true answer and compute the loss. Backward pass: we compute how much each weight contributed to the loss. Update: we change the weights a little to reduce future loss. Today’s focus is the backward pass. It uses the structure of the network to distribute responsibility for the error. 3) Gradients: the direction of steepest uphill The key tool in backpropagation is the gradient . A gradient tells us how a small change in a number will change the loss. If changing a weight upward increases the loss, the gradient is positive. If changing it upward decreases the loss, the gradient is negative. In plain language, the gradient answers: “If I nudge this weight a tiny bit, does the model get better or worse, and by how much?” Why is that useful? Because training usually moves in the opposite direction of the gradient. If a weight is pushing the loss upward, we reduce it; if it is helping, we may increase it. This is the idea behind gradient descent , the common update rule used to train neural networks. Gradient descent means “take a small step downhill on the loss surface.” A loss surface is the landscape of possible loss values for different weight settings. Imagine standing on a hill in fog. You cannot see the whole mountain, but you can feel which direction goes downhill. The gradient is your local compass. 4) Why “back” propagation works Each layer in a neural network does two things: it takes in numbers and transforms them. If a later layer makes an error, that error depends on the outputs of earlier layers. So to find out how much earlier weights mattered, we apply the chain rule from calculus. The chain rule is a rule for combining small effects in a sequence. If one quantity depends on another, and that one depends on a third, the chain rule lets us figure out the total effect of changing the first quantity on the final result. You do not need the full math today. The practical idea is simpler: backpropagation starts at the output, where the error is visible, and moves backward layer by layer, calculating “blame” for each weight based on how much it influenced the final output. This is why the process is called backpropagation: the error signal flows backward through the same structure that the input flowed through forward. 5) A concrete example: predicting house prices Suppose a network tries to predict house prices from two inputs: square footage and number of bedrooms. It predicts $310,000 , but the true price is $350,000 . The loss says the prediction is too low. During the backward pass, the network asks questions like: Did the final output layer push the price too far downward? Did one hidden layer shrink the signal too much? Did the weight connected to “square footage” matter more than the weight connected to “bedrooms”? Backpropagation computes gradients for each of those weights. If the “square footage” weight had too little influence, its gradient may suggest increasing it. If a bias was pulling the output down too much, the gradient may suggest increasing that bias. The important point is that the model does not guess randomly which part was at fault. It uses the network’s structure to trace the error back through the chain of decisions. Review pause: connect this to earlier lessons From Day 20 , remember that each layer produces a new representation. Backpropagation tells each layer how to adjust that representation-making process so the final answer improves. From Day 18 , remember calibration and confidence. A model can be confidently wrong. Backpropagation is one of the mechanisms that helps reduce those errors over time by adjusting the parameters that produced them. And from Day 16 , recall that linear models are limited. Neural networks improve on them partly because backpropagation lets many layers learn useful nonlinear behavior together. Free hands-on exercise: trace a tiny network by hand You can do this with pencil and paper, or in a plain notes app. No paid tools are needed. Draw a tiny network with one input, one hidden unit, and one output. Choose simple numbers, such as input 2 , weight 1 3 , weight 2 4 , and target output 30 . Compute the forward pass: input times weight 1, then that result times weight 2. Compute the loss as the difference between prediction and target, using absolute difference or squared difference. Now ask: if weight 2 were a little larger, would the prediction rise or fall? If weight 1 were a little larger, what would happen indirectly through the hidden unit? Write a sentence for each weight: “This weight should probably go up/down because it pushes the output too low/high.” This is not full formal backpropagation, but it trains the same mental habit: follow the effect of each weight all the way to the final error. Three common misunderstandings Backpropagation is not the same as the optimizer. Backpropagation computes gradients. An optimizer, such as gradient descent, uses those gradients to actually update the weights. Backpropagation does not “understand” the task. It only measures how changes to weights affect the loss. Backpropagation is not magic memory. The network still needs many examples and many updates. One backward pass only gives local feedback for one batch or one example. Why this matters Backpropagation is one of the main reasons neural networks can learn complex tasks. It turns a hard problem—“Which part of the network caused the mistake?”—into a systematic calculation. Without it, training deep models would be much less practical. In short: the forward pass makes a guess, the loss measures the mistake, gradients describe how each weight influenced that mistake, and backpropagation carries that information backward so the model can improve. Knowledge check 1) What is the difference between the loss and the gradient? 2) Why does backpropagation move backward through the network instead of only looking at the output layer? 3) In one sentence, what does gradient descent do with the information produced by backpropagation? ------------------------------ Answers 1) The loss is a single number measuring how wrong the prediction was; the gradient tells how changing a specific weight would change that loss. 2) Because earlier layers affect later layers, so the error has to be traced backward through the chain to assign credit or blame to all relevant weights. 3) Gradient descent uses the gradients to adjust weights in the direction that reduces future loss.
