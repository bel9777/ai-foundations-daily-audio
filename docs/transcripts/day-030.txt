AI Foundations — Day 30: Fine-Tuning and Instruction Following

Day 30 — Fine-Tuning and Instruction Following Objective: By the end of today’s lesson, you will understand what fine-tuning is, why instruction following matters, how examples change model behavior, and when to use a general model versus a specialized one. Prerequisites: You should be comfortable with tokens, context windows, pretraining, next-token prediction, and the basic transformer idea from the last few days. 1) Why we need more than pretraining Yesterday you learned that a language model is trained to predict the next token , which means it becomes good at continuing text. That is powerful, but it does not automatically make the model a good assistant. A model trained only on huge amounts of text may know facts and patterns, yet still answer in a vague, inconsistent, or overly verbose way. This is where fine-tuning comes in. Fine-tuning means taking a model that already learned general language patterns and giving it additional training on a smaller, targeted dataset so it behaves better for a specific task. Think of pretraining as learning the whole language, and fine-tuning as learning how to use that language for a job. A general model is like a capable graduate who has studied many subjects. Fine-tuning is like giving that graduate a short apprenticeship for a specific role. 2) Fine-tuning: shaping a model for a task A dataset is a collection of examples used for training or testing. In fine-tuning, the dataset often contains pairs such as: a user request, and a desired response. For example, a customer-support model might be fine-tuned on many examples of complaint messages paired with calm, helpful replies. A medical note model might be fine-tuned on examples of short clinical summaries written in a specific style. Fine-tuning changes the model’s weights, which are the internal numbers that control how strongly the model responds to patterns. In plain language, it nudges the model toward the behavior we want. Important idea: fine-tuning does not usually teach a model everything from scratch. It builds on what the model already knows. 3) Instruction following: learning the shape of a good answer Instruction following means producing responses that match the user’s request. The instruction might ask for a summary, a list, a friendly tone, a specific format, or a step-by-step explanation. To follow instructions well, a model needs to learn more than facts. It needs to learn response structure , which is the pattern of how to organize an answer. For example: If the user says “explain like I’m five,” the model should simplify. If the user says “give me three bullet points,” the model should count carefully. If the user says “be brief,” the model should avoid long digressions. Instruction tuning is a type of fine-tuning focused on examples where the model learns how to respond to instructions. The goal is not just correctness, but usefulness in the format the user asked for. 4) One analogy: teaching a chef new service styles Imagine a chef who already knows how to cook many dishes. That is like a pretrained model: broad knowledge and useful skills. Now imagine the chef starts working at a quiet café, a fast food counter, and a formal banquet hall. The recipes may be similar, but the service style changes each time. Fine-tuning is like teaching the chef the local habits of each workplace. Instruction following is like teaching the chef to listen carefully: “Make it quick,” “Serve it in three items,” or “Keep the tone formal.” The chef does not forget how to cook; they learn how to serve in the right way. 5) A real-world example Suppose a small company wants an AI assistant for internal HR questions. The general model may already know broad information, but the company wants answers to match policy language, use a polite tone, and avoid guessing. The team could fine-tune the model on approved HR question-and-answer pairs. After fine-tuning, the model is more likely to answer in the company’s preferred style. It may be better at saying, “According to policy, here is the process,” instead of giving an informal or inconsistent answer. This is a practical example of how fine-tuning supports instruction following in a specific setting. 6) What can go wrong Fine-tuning is useful, but it has limits. Overfitting means the model learns the training examples too specifically and performs poorly on new examples. Catastrophic forgetting means the model loses some general skills while becoming better at the narrow task. Low-quality data can teach the model bad habits, such as unclear answers or inconsistent formatting. So the quality of the fine-tuning examples matters a great deal. A small set of clean, well-written examples is often better than a larger set of messy ones. 7) When to fine-tune, and when not to Fine-tuning is helpful when you want: a specific style or format, domain-specific language, more consistent responses, or a task the base model does not do reliably. You may not need fine-tuning if a well-written instruction in the prompt already works well. In many cases, prompting is enough. Fine-tuning is more like changing the engine’s settings, while prompting is like giving the driver better directions. Use the lighter tool first when it works. Free hands-on exercise You do not need paid tools for this exercise. Use a text editor or notebook. Write five user requests for the same topic, such as “explain photosynthesis,” “summarize a meeting,” or “draft a polite email.” For each request, write a good target answer in the exact style you want the model to imitate. Now inspect your five pairs and look for patterns. Ask yourself: What style rules repeat? How short or long should the answer be? What phrases signal a helpful response? What would make a bad example? This is the core of instruction tuning: many examples of the right behavior so the model can generalize the pattern. Spaced review Let’s connect today’s topic to two earlier lessons. From Day 27: Tokens and Context Windows , remember that a model can only pay attention to the text inside its context window. Fine-tuning does not change that window by itself; it changes what the model tends to do with the text it can see. From Day 28: Pretraining , remember that large corpora teach broad language patterns. Fine-tuning builds on that foundation instead of replacing it. The model first learns general language, then learns a narrower behavior from examples. From Day 29: Next-Token Prediction , remember that the base training objective is simple: predict the next token. Fine-tuning changes what kinds of next-token predictions are rewarded, especially when the target responses show a clear instruction-following pattern. Knowledge check In plain language, what is fine-tuning? Why are high-quality examples important for instruction following? What is one case where prompting may be enough and fine-tuning may not be necessary? ------------------------------ Answers Fine-tuning is additional training that adjusts a pretrained model so it behaves better on a specific task or style. High-quality examples teach the model the right response patterns; low-quality examples can teach bad habits or inconsistent behavior. If a clear prompt already gets the desired result, such as asking for a short summary in a specific format, prompting alone may be enough.
