AI Foundations Day 2: How Machines Learn From Examples Hi Brian, Welcome to Course Day 2. Yesterday, the course began with the big picture: artificial intelligence is software that performs tasks we usually associate with human intelligence, such as recognizing patterns, making predictions, generating language, or choosing actions. Today we move from definition to mechanism: how a machine learning system improves by learning from examples instead of being manually programmed for every situation. Estimated time: 8-12 minutes Prerequisites: You only need yesterday's mental model: AI is a broad field, and machine learning is one major way to build AI systems. No math or coding is required today. Objective By the end of this lesson, you should be able to explain what machine learning is, why examples matter, and how a model uses training data to make predictions on new cases. 1. Machine Learning: Programming With Examples Traditional software follows explicit instructions written by people. Example: > If the temperature is below 32°F, show "freezing." Otherwise, show "not freezing." Machine learning works differently. Instead of writing every rule by hand, we give the system many examples and let it find useful patterns. Example: > Here are thousands of house listings with their features and sale prices. Learn the relationship between the features and the price so you can estimate the price of a new house. New term: Machine learning A way of building AI systems where software learns patterns from data and uses those patterns to make predictions, classifications, recommendations, or decisions. Machine learning is useful when the rules are hard to write manually. It would be difficult to list every rule for recognizing spam email, detecting credit card fraud, estimating crop yield, or understanding spoken words. But examples can reveal patterns. 2. Data: The Examples a Model Learns From A machine learning system learns from data . Data can be numbers, text, images, audio, clicks, purchases, sensor readings, or almost any recorded information. For beginner purposes, think of each example as having two parts: - Inputs: The information the model gets to look at. - Output: The answer we want the model to learn, when an answer is available. Concrete example: House size Bedrooms Distance to town Sale price ---: ---: ---: ---: 1,200 sq ft 3 4 miles $240,000 2,100 sq ft 4 8 miles $390,000 900 sq ft 2 1 mile $220,000 Here, the house size, bedroom count, and distance to town are inputs. The sale price is the output. New term: Training data The examples used to teach a machine learning model. New term: Label The known answer attached to a training example. In the table above, the sale price is the label. Not all machine learning uses labels, but labeled examples are the easiest starting point. 3. Models: Pattern-Finding Machines A model is the part of the system that learns patterns from training data. At first, a model may make poor guesses. During training, it compares its guesses to the correct answers and adjusts itself to do better next time. For the house price example, the model might learn patterns like: - Larger houses usually cost more. - More bedrooms often increase price. - Distance to town may affect price, depending on the area. The model is not memorizing one perfect rule. It is learning a pattern that can hopefully work on houses it has never seen before. New term: Model A learned pattern or mathematical structure that takes inputs and produces an output, such as a prediction or classification. New term: Training The process of adjusting a model so its outputs become more accurate on examples. 4. Prediction: Using the Model on Something New After training, we use the model on a new example. Suppose we ask: House size Bedrooms Distance to town Sale price ---: ---: ---: ---: 1,600 sq ft 3 5 miles ? The model uses the patterns it learned to predict the missing sale price. New term: Prediction The output a model produces for a new input. Predictions are not always about the future. A prediction can mean: - "This email is probably spam." - "This image probably contains a stop sign." - "This customer may cancel next month." - "This sentence likely means the user wants a refund." In AI, prediction often means "the model's best answer based on learned patterns." 5. Generalization: The Real Goal A model that only memorizes training examples is not very useful. The real goal is for it to perform well on new examples. New term: Generalization A model's ability to work well on new cases it did not see during training. This is one of the most important ideas in AI. A model may look good if you test it only on examples it already studied. The real question is whether it can handle new, realistic situations. Analogy: Teaching by Examples, Not Rules Imagine teaching someone to identify ripe tomatoes. You could try to write rules: - Redness above a certain level means ripe. - Firmness must be within a certain range. - Size should be considered. - Surface texture matters. But that gets complicated fast. Instead, you might show many examples: - This tomato is ripe. - This one is underripe. - This one is overripe. - This one looks red but is still too firm. Over time, the person learns the pattern. Machine learning is similar: examples shape the system's judgment. Concrete AI Example: Spam Detection Spam detection is a classic machine learning task. Training data might include thousands of emails labeled as either "spam" or "not spam." Inputs could include: - Words in the subject line. - Links in the message. - Sender reputation. - Formatting patterns. - Whether many users marked similar messages as spam. The label is: - Spam. - Not spam. After training, the model receives a new email and predicts whether it should go to the inbox or spam folder. Important point: no person needs to manually write every spam rule. The model learns many small signals from examples. Free Hands-On Exercise No tools required. Use paper, a notes app, or a spreadsheet. Create a tiny training dataset for a model that predicts whether you would want to read an email immediately. Make 8 example rows with these columns: Sender type Subject urgency Is it from a real person? Read immediately? --- --- --- --- coworker high yes yes newsletter low no no Use your own examples. Then answer: 1. Which columns are the inputs? 2. Which column is the label? 3. What simple pattern might a model learn? 4. What is one new email where the model might make a mistake? The point is not to build a real model. The point is to see machine learning as learning from structured examples. Knowledge Check 1. What is the main difference between traditional programming and machine learning? 2. In a house price dataset, if the known sale price is what we want the model to learn, what is that known answer called? 3. Why is generalization more important than memorizing training examples? --- Answers 1. Traditional programming uses rules written directly by people. Machine learning learns patterns from examples. 2. The known answer is called a label . 3. Because the model needs to work on new, realistic cases it did not see during training. Memorization can look accurate on old examples but fail on new ones. Spaced Review From Day 1: - Artificial intelligence is the broad field of making software perform tasks associated with human intelligence. - Machine learning is one way to build AI, based on learning patterns from data. - Not all AI is generative AI. Generative AI is a specific type of AI that creates new content, such as text, images, audio, or code. From today: - Training data provides examples. - A model learns patterns from those examples. - A prediction is the model's output for a new input. - Generalization is the ability to handle new cases, not just remembered ones.
