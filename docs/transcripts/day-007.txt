AI Foundations — Day 7: Classification, Regression, and Decision Boundaries

Day 7: Classification, Regression, and Decision Boundaries Objective: By the end of today, you should be able to tell the difference between classification and regression , explain what a decision boundary is in plain language, and recognize when an AI system is making one kind of prediction versus the other. Prerequisites: You should already be comfortable with the ideas from Days 1–6: what AI is, how it finds patterns, the basic machine learning workflow, why generalization matters, how data acts as the model’s experience, and how labeled examples help a model learn. Today we’re focusing on the kind of answer a model is trying to produce. Some models choose between named categories. Others predict a number. That difference is more important than it may first seem, because it changes how we train the model, how we judge its performance, and what “good” looks like. 1) Classification: choosing a category Classification is a machine learning task where the model predicts a class , which is a category or label. A class can be something like spam vs. not spam , cat vs. dog , or approved vs. denied . In classification, the output is not a number on a scale. It is a label. A model may also assign a probability, which is a number between 0 and 1 that represents how confident it is about each class. For example, it might say there is a 90% chance an email is spam. Because of Day 6: learning from labeled examples , classification makes sense when your training data includes inputs paired with correct labels. If you want the model to learn spam detection, you show it emails that were already labeled spam or not spam. 2) Regression: predicting a number Regression is a machine learning task where the model predicts a continuous value , meaning a number that can take many possible values along a range. Examples include: Predicting a house price Estimating the temperature tomorrow Forecasting how many minutes a commute will take Here, the answer is not a label like spam or not spam . It is a number like $412,000 or 27 minutes . Small differences matter, so we judge regression by how close the prediction is to the true value. 3) Decision boundaries: the line between classes A decision boundary is the dividing line, curve, or surface that separates one class from another. It is the point at which the model switches from predicting one label to predicting a different label. Imagine a model trying to separate apples from oranges using two features: size and color. If you drew a chart with apples on one side and oranges on the other, the decision boundary would be the invisible border between the two groups. Memorable analogy: think of a decision boundary like the line in a store where one cashier lane ends and the next begins. If you are on one side, you go to lane A. If you cross the line, you go to lane B. The model is doing a similar kind of sorting, just with numbers instead of people in a store. 4) How these ideas connect Classification and regression are both prediction tasks , but they answer different questions: Classification: “Which category is this?” Regression: “What number should we predict?” The model’s features are the pieces of input it uses to make the prediction. A feature is any measurable detail, such as email length, house size, or number of previous purchases. Earlier in the course, we said data is the model’s experience. Today, that experience becomes useful only when the features help the model draw a useful boundary or estimate a useful number. And because of Day 4: generalization , we care not just about fitting the training data, but about whether the boundary or number prediction still works on new data the model has never seen. 5) A concrete real-world example: loan decisions Suppose a bank wants to use AI in lending. If the goal is to predict whether a loan application should be approved or rejected , that is classification . If the goal is to predict the likely amount of monthly payment , that is regression . The first task might learn a decision boundary separating applicants into two groups. The second task might learn how several features combine to produce a number. This is why the task definition matters. If you ask a model to solve the wrong kind of problem, even a very good model can give the wrong kind of answer. Quick review of earlier ideas From Day 2: AI systems look for patterns, but patterns only help when they match the problem you want to solve. From Day 3: the machine learning workflow starts with the problem definition. Classification and regression are part of that definition. From Day 6: labeled examples teach the model what the correct categories or numbers should be. Free hands-on exercise You do not need paid tools for this. Knowledge check 1) What is the main difference between classification and regression? 2) What is a decision boundary? 3) Why does the task definition matter before training a model? ------------------------------ Answers 1) Classification predicts a category or label, while regression predicts a number on a range. 2) A decision boundary is the dividing line, curve, or surface that separates one class from another. 3) Because the model needs the right kind of target to learn from, and because classification and regression are judged differently and solve different problems.
